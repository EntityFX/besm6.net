# Адрес запроса и смена приписки

`MemoryRequestAddress` хранит 15-битный адрес и признак физического адреса.
`PageAssignment.TranslateRequest` применяет текущую таблицу приписки в момент
перевода запроса. Если признак физического адреса установлен, преобразования
нет. Это отдельный компонент границы обращения к памяти; он не подключён
к выборке/записи CPU и не заменяет пока физические теги действующих буферов.

## Проверенные источники

ТО устройства управления, ИЫ1.700.000 ТО-2, редакция 1–65:

- [Первая часть скана](https://www.besm6.org/doc/БЭСМ6-ТО-III.I-часть1-устройство-управления.pdf),
  листы 30–31 (PDF 17): преобразование адреса перед выдачей в МОЗУ.
  SHA-256: `33521aab235c4a252f00c963a22d340138ec8990ddec38e22c81a89a6553bd74`.
- [Вторая часть скана](https://www.besm6.org/doc/БЭСМ6-ТО-III.II-часть2-устройство-управления.pdf),
  §4.22, лист 66 (PDF 15): замена пяти старших разрядов при выдаче адреса;
  §4.30, листы 94–95 (PDF 26): физический адрес отмечен дополнительным
  разрядом 16 в перечисленных промежуточных регистрах, включая РАЗ,
  СчАС и ВРАМ. SHA-256:
  `762f7b20a826a3bb94cd82c563c0533ea7edced8e46732dbc17870c052e60002`.
- [ТО системы команд](https://www.besm6.org/doc/БЭСМ6-ТО-IX-описание-системы-команд.pdf),
  редакция 1–67, §4.24, лист 107: до смены приписки требуется переслать
  БРЗ и обеспечить завершение ранее накопленных команд.
  SHA-256: `7412b2c1c90195e029fe5b0067e859ce6c6f846a780062de8ab6ab4f96b6c113`.

Названия частей архивных файлов не совпадают с надписью «книга 1»
на просмотренных разворотах. В ссылках указан файл архива, а номера листов
считаны с самих изображений. Разворот PDF содержит два печатных листа.

Формат запроса закрепляет проверенные признаки промежуточного адреса.
Из него **не выводится** ключ сравнения всех БАЗ/БАС: для полного подключения
ещё нужно подтвердить распространение признака по этим узлам и согласовать
различия редакций. Описание очередности БРЗ в §4.18–4.20 редакции 1–65
не подменяет действующий функциональный порядок по ТО-8 редакции 1–67.

Продолжение сверки подтвердило отдельное хранение `16рБАС` по §4.3,
листу 51 первой части. Это уточняет состояние командного буфера, но ещё
не полный состав условий совпадения. Подробности и текущая матрица:
[готовность этапов](besm6-readiness.md).

## Граница трансляции

Нулевой операнд и пультовые адреса разрешаются до поступления запроса
в обычную МОЗУ. `TranslateRequest` выполняет только замену номера страницы:
математический адрес 0 в этом API также переводится по таблице, а физический
0 остаётся 0. Это не правило чтения гостевого операнда по нулевому адресу.
Для правил допуска используются `ResolveOperand`/`ResolveInstruction`.

Маска защиты не проверяется повторно в `TranslateRequest`: метод не
считывает данные, не определяет приоритет ошибок и не доставляет прерывания.
Нулевая приписка также не создаёт ошибку команды на этой границе;
запрет проверяется при допуске команды. Значение запроса неизменно,
результат перевода нельзя сохранять после смены таблицы без протокола.

## Функциональная смена приписки

`MemoryMappingController` связывает `PageAssignment` и `BufferedMemory`
через явно вызываемый API хоста:

1. Проверяет весь запрос изменения, включая неподдерживаемый разряд 64K.
2. Публикует отложенные физические записи БРЗ.
3. Изменяет одну страницу либо группу из четырёх страниц.

Неверный запрос не публикует записи и не меняет таблицу. Уже выбранные
физические адреса записей сохраняются: пересылка попадает в прежние ячейки.
Чистые копии БРЗ не переписывают МОЗУ, порядок буферов и БРС сохраняются.
Контроллер не очищает БРС автоматически.

Это программная координация существующих физических буферов, а не ЗпР,
не исполнение исторических восьми/девяти записей и не сериализация АУ.
Низкоуровневые setters `PageAssignment` по-прежнему доступны без пересылок;
вызывающий код должен выбирать подходящий контракт. Контроллер не наблюдает
чужие прямые изменения таблицы и не обеспечивает многопоточную блокировку.

Скорости original/max, часы, обработчики команд, режимы машины и CLI
не меняются. Подключение математических тегов к CPU остаётся отдельным блоком.
