# Статья о производительности БЭСМ-6

Готовый текст: [article.md](article.md). Оценка чтения — 33–35 минут. Результаты относятся к симулятору и его модели времени; физическая БЭСМ-6 не использовалась.

Материалы:

- [Таблица результатов и разброс](benchmark-results.md): 48 проверенных запусков, восемь заданий, два режима, три повтора.
- [CSV](data/run-2026-10-13/results.csv), [JSON со статистикой](data/run-2026-10-13/results.json), [окружение и хеши](data/run-2026-10-13/environment.json).
- [Аудит источников](source-audit.csv) и [результат проверки комплекта](verification.json).
- `assets/`: три иллюстрации в PNG для публикации и SVG для редактирования.
- `data/run-2026-10-13/`: восемь входных колод, конфигурация и все 48 журналов.

Сборка и повторение измерений из корня репозитория:

```bash
dotnet build src/Besm6.Cli -c Release
python3 docs/articles/besm6-performance/measure.py \
  --output /tmp/besm6-performance-repeat --repeats 3
```

Каталог результата должен быть новым. `measure.py` использует только стандартную библиотеку Python и запускает задания последовательно. Режимы можно выбирать через `--modes original virtual max`; опубликованный комплект содержит только `original` и `virtual`.

Повторная проверка сохранённых журналов и ссылок:

```bash
python3 docs/articles/besm6-performance/verify.py --check-web
```

Проверка сравнивает численные результаты между режимами и повторами, сверяет журналы с JSON, проверяет локальные ссылки и оценивает объём текста. HTTP 403 у Stack Exchange означает ограничение автоматического доступа: содержание источника прочитано через веб-инструмент, ошибка не считается доказательством исчезновения страницы.

Перестроение графиков и таблиц из опубликованного набора:

```bash
python3 -m venv /tmp/besm6-performance-plots
/tmp/besm6-performance-plots/bin/pip install matplotlib
/tmp/besm6-performance-plots/bin/python \
  docs/articles/besm6-performance/render.py
```

`render.py` создаёт отдельный `measured-section.md`; редакторские изменения основной статьи автоматически не перезаписываются. В данном комплекте использовался matplotlib 3.11.2.
