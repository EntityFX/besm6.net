# Визуализатор чисел и команд БЭСМ-6

Учебное Windows-приложение (.NET 8, Windows Forms), которое позволяет набирать
числа и команды отдельными битами, превращает их в понятное человеку
представление и добавляет в общий журнал подробный русскоязычный разбор.

## Предварительные требования

- Windows 10/11
- .NET 8 SDK

## Запуск

```powershell
dotnet run --project src/Besm6.BitVisualizer.WinForms/Besm6.BitVisualizer.WinForms.csproj
```

Все расчёты выполняются локально, данные никуда не отправляются.

## Возможности

Пять рабочих вкладок:

1. **Число БЭСМ-6** — 48 бит: семибитный смещённый порядок (смещение 64) и
   знаковая 41-битная мантисса в дополнительном коде.
2. **Целые числа** — 8/16/32/64 бит. Флажок «Знаковое число (дополнительный
   код)»: включён — верхний бит трактуется как знак (−2^(n−1)), выключен — все
   разряды положительные.
3. **IEEE-754** — binary16 (Half), binary32 (float), binary64 (double);
   нормальные и субнормальные числа, нули, бесконечности, NaN.
4. **Команда БЭСМ-6** — 24 бита: индекс-регистр M0–M15, форматный бит 19
   (длинная/короткая команда), код операции с мнемоникой, адрес.
5. **Системы счисления** — перевод целых чисел между основаниями 2–36 с
   показанием накопления цифр и повторного деления.

## Разметка битовой сетки

Биты идут от старшего (слева) к младшему (справа) выровненными блоками по
восемь. Цвет кодирует семантическую категорию поля и продублирован подписью:

- мягкий красный — знак;
- золотистый — порядок / признак формата;
- голубой — мантисса / дробная часть;
- фиолетовый — код операции;
- зелёный — регистр;
- нейтральный сине-серый — адрес и обычные разряды значения.

## Общий журнал

Внизу окна постоянно виден общий журнал. Каждая операция добавляет блок:

```
[18:42:10] БЭСМ-6 — нативное 48-битное число
Вход: 010000000000...₂ (0400000000000000₈)
1. Семь старших битов 47–41 дают смещённый порядок: 64.
2. Истинный порядок: 64 - 64 = 0.
...
Результат: 1
```

Ошибки ввода тоже записываются отдельным блоком с объяснением; ранее
накопленная история не удаляется. Кнопки **Копировать** (весь текст в
буфер обмена) и **Очистить** (сброс журнала).

## Сборка и тесты

```powershell
dotnet build Besm6.sln -c Release
dotnet test tests/Besm6.Architecture.Tests/Besm6.Architecture.Tests.csproj -c Release
dotnet test tests/Besm6.BitVisualizer.WinForms.Tests/Besm6.BitVisualizer.WinForms.Tests.csproj -c Release
```

Ядро (`Besm6.Architecture`, папка `Visualization`) не зависит от Windows Forms
и покрывается тестами без запуска формы.
