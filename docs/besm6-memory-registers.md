# Формат регистров приписки и защиты

Источник: ИЫ1.700.000 ТО-8, редакция 1–67,
[скан системы команд](https://www.besm6.org/doc/БЭСМ6-ТО-IX-описание-системы-команд.pdf),
§4.23–4.30, листы 106–109. Таблицы и текст проверены по изображениям.
SHA-256: `7412b2c1c90195e029fe5b0067e859ce6c6f846a780062de8ab6ab4f96b6c113`.

Нумерация разрядов в ТО начинается с 1; в C# с 0.

| Поле в группе РП | Разряды сумматора: пять младших | Дополнительный разряд | Математическая страница |
|---|---|---|---|
| 0 | 1–5 | 29 | 4 × group |
| 1 | 6–10 | 30 | 4 × group + 1 |
| 2 | 11–15 | 31 | 4 × group + 2 |
| 3 | 16–20 | 32 | 4 × group + 3 |

РП0–РП7 соответствуют исполнительным адресам ЗпР 020–027 (восьмеричным).
Лист 109 описывает расширение до 64 физических страниц: дополнительный
разряд расширяет номер страницы, математический адрес остаётся 15-битным.

`PageAssignment.ImportAssignmentGroup(group, accumulator)` переносит
поля по этой таблице. Компонент рассчитан на 32K и **отклоняет** любой
установленный дополнительный разряд до изменения всех четырёх страниц.
Это проверка конфигурации API хоста, а не утверждение о реакции реальной
машины 32K и не гостевой авост. Другие поля сумматора не используются.

`ImportProtectionGroup(group, accumulator)` переносит разряды 21–28
в восемь разрядов выбранного РЗ, сохраняя остальные 24 разряда маски.
РЗ0–РЗ3 соответствуют адресам ЗпР 030–033, каждый охватывает восемь
математических страниц. Разряд 21 соответствует младшей странице группы.
Остальные разряды сумматора не используются.

Например, буквальный код `0x20C41` задаёт четыре номера РП `1, 2, 3, 4`.
Код `0xA500000` задаёт байт защиты `0xA5`. Это контрольные примеры,
выведенные из таблиц, а не примеры из книги.

## Границы API

Методы принимают **индекс группы**, не адрес ЗпР. Они не проверяют
привилегии, не выполняют пересылку БРЗ и не продвигают часы. Лист 107
требует пересылки БРЗ до смены приписки и завершения накопленных команд.
Поэтому импорт не вызывается из обработчиков CPU и не выдаётся за
аппаратную команду ЗпР. Холодный сброс и начальные значения не определяются.

Для дальнейшего подключения остаются аппаратные теги БАЗ/БАС,
протокол пересылок, режим супервизора и состояние CPU на сигнале защиты.
Прежняя память и активный путь Buffered этим изменением не меняются.

## Проверки

227 новых случаев: каждый из 160 младших разрядов РП, каждый из 32
дополнительных разрядов с атомарным отказом для 32K, все 32 разряда РЗ,
буквальные примеры, неиспользуемые разряды, сохранение соседних групп,
проверка защиты после импорта и недопустимые индексы.
