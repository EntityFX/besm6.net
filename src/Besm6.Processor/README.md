# Besm6.Processor

Исходники сгруппированы по ответственности внутри одной DLL.
Пространства имён и публичные контракты сохраняются.

| Папка | Назначение |
|---|---|
| `Arithmetic/` | АУ — общий арифметический вычислитель |
| `Cpu/` | единые регистры и фасад процессора |
| `Diagnostics/` | трассировка, снимки и watchpoints |
| `Execution/` | исполнение команд и управление функциональной симуляцией |
| `Memory/` | память, приписка, защита и буферы |
| `Properties/` | метаданные сборки |
| `Supervisor/` | УУ — привилегированное состояние, прерывания и контракты ввода-вывода |

[Границы проектов и владельцев исполнения](../../docs/source-layout.md).
