# Besm6.Processor

Исходники сгруппированы по ответственности внутри одной DLL.
Публичные роли разделены: `IProcessor` управляет исполнением и наблюдением,
`IRegisterOps` редактирует регистры, `IAlu` выполняет арифметику,
`IProcessorDebug` задаёт подписки и watchpoints, а `IInstructionAccountingSource`
управляет сеансами учёта. `State` — живое представление только для чтения;
`ProcessorSnapshot` сохраняет неизменяемую копию. Запись R всегда ограничена шестью битами.

Runtime получает внутренние контракты `IFunctionalProcessorExecution` и
`IPreparedProcessorExecution`. Подготовленная команда является одноразовой
арендой, привязанной к владельцу и поколению; регистры и семантика команд общие.

CPU принимает `IOperandMemory`; backend с `IInstructionMemory` предоставляет
отдельную выборку команд. Buffered/Mapped отделяют coherent host-представление
`IHostMemory` от CPU-доступа. Публикация hosted CTX выполняется через
`ICommandMemory`, сохраняя правила приписки и алиасов. Реализация диагностики
внутренняя. Friend-доступ имеют Runtime, Processor.Tests и Runtime.Tests;
CLI работает только через публичные роли.

| Папка | Назначение |
|---|---|
| `Arithmetic/` | АУ — общий арифметический вычислитель |
| `Cpu/` | единые регистры и фасад процессора |
| `Diagnostics/` | трассировка, снимки и watchpoints |
| `Execution/` | исполнение команд и управление функциональной симуляцией |
| `Memory/` | память, приписка, защита и буферы |
| `Properties/` | метаданные сборки |
| `Supervisor/` | УУ — привилегированное состояние, прерывания и контракты ввода-вывода |
