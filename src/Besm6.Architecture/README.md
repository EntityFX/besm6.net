# Besm6.Architecture

Исходники сгруппированы по ответственности внутри одной DLL.
Сборка содержит значения ISA и публичные контракты без зависимости от реализации.
`IReadOnlyRegisters` и `IProcessorState` предназначены для наблюдения;
`IRegisters`/`IRegisterOps` — для явного редактирования. Исполнение, арифметика,
диагностика и учёт имеют отдельные интерфейсы. Внутренние переходы состояния
и протокол подготовленной команды находятся в Processor.

Доступ к памяти разделён на `IHostMemory` (согласованная загрузка/наблюдение),
`IOperandMemory` (операнды CPU), `IInstructionMemory` (выборка с контролем)
и `ICommandMemory` (hosted CTX). `IMemory` задаёт только транспорт слова;
приписка, защита и побочные эффекты определяются конкретной ролью и моделью.
Внутреннее состояние watchpoints и управляющие исключения находятся в Processor.

| Папка | Назначение |
|---|---|
| `Isa/` | система команд и кодирование |
| `Machine/` | роли процессора, регистры, снимки и архитектурные константы |
| `Memory/` | слова памяти, запросы и контракты доступа |
| `Debug/` | контракты диагностики и записи трассировки |
| `Supervisor/` | привилегированные режимы и контракты УУ |
| `Numerics/` | 48-разрядные числа |
| `State/` | архитектурные режимы и флаги |
