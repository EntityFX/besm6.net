Инструкция пользователя

              
Веб-консоль запускает программы БЭСМ-6 на сервере. Для каждого подключения создаётся отдельная машина; устанавливать симулятор на свой компьютер не нужно.

              
Первый запуск

              
  1. Дождитесь надписи «Подключено» в верхней панели.
  2. Откройте , найдите fortran.dub и нажмите «Загрузить в машину».
  3. Выберите «Полный запуск» и нажмите «Пуск». Результат программы смотрите во вкладке «Печать».

              
Своя программа

              
Перетащите файл .dub в область задания или выберите его с диска. Лимит файла — 10 MB. Во вкладке «Редактор» можно изменить копию примера или ввести программу (до 1 MB), затем загрузить её в машину. Правка текста не меняет уже загруженную программу.

              
Режимы машины и скорость

              
Для Фортрана, Алгола и ассемблерных заданий .dub выберите Dubna. Для Supervisor нужна конфигурация машины .json; шаблон доступен в редакторе. Максимальная скорость предназначена для быстрого запуска, историческая использует модель времени БЭСМ-6, виртуальная — таймер хоста. Лимит времени 0 означает отсутствие ограничения.

              
Отладка

              
В режиме «Отладка» запуск останавливается на паузе. «Шаг» выполняет одну команду, «Продолжить» возобновляет выполнение, «Пауза» приостанавливает его. Регистры и память показаны слева. OCT, DEC и HEX переключают систему счисления; адрес вводится в выбранной системе. Автообновление показывает состояние во время работы, но может замедлять исполнение.

              
Результаты и устройства

              
«Печать» показывает листинг и результаты. Во вкладках «Перфокарты» и «Плоттер» доступны вывод соответствующих устройств. Если программа ждёт ввод, откроется «Терминал»: введите строку и отправьте её. «Накопители» позволяют читать и подключать образы при остановленной машине; встроенные ленты уже включены в поставку. «Кодер команд» преобразует 24- и 48-битные значения и мнемоники.

              
Остановка и сессия

              
«Остановить» прекращает выполнение, «Сброс» очищает машину и её вывод. При разрыве соединения сессия и загруженные файлы теряются: после подключения загрузите задание заново. Для параллельных запусков откройте отдельные вкладки браузера.

              
Язык интерфейса

              
Русский и английский переключаются в верхней панели. Выбор сохраняется в этом браузере. Язык интерфейса не изменяет исходный код, мнемоники и вывод гостевой программы.

            

            

              
User guide

              
The web console runs BESM-6 programs on the server. Each connection gets its own machine; no simulator installation is needed on your computer.

              
First run

              
  1. Wait for Connected in the top bar.
  2. Open , select fortran.dub and click Load into machine.
  3. Select Full run and click Run. Open Printer to see the program output.

              
Your own program

              
Drop a .dub file onto the job area or browse for it (up to 10 MB). In Editor you can edit a copy of an example or enter a program (up to 1 MB), then load it into the machine. Editing does not change the program already loaded.

              
Machine models and speed

              
Choose Dubna for Fortran, Algol and assembly .dub jobs. Supervisor needs a .json machine configuration; a template is available in Editor. Maximum runs as fast as possible, Original uses the BESM-6 timing model, and Virtual uses the host clock. A time limit of 0 means unlimited.

              
Debugging

              
Debug mode starts paused. Step executes one instruction, Resume continues, and Pause suspends execution. Registers and memory are on the left. OCT, DEC and HEX change the number base; enter addresses in the selected base. Auto-refresh updates state during execution and can reduce performance.

              
Output and devices

              
Printer shows listings and results. Punch cards and Plotter show device output. When a program requests input, Terminal opens: enter a line and send it. Storage lets you read and mount images while the machine is stopped; built-in tapes are included. Instruction codec converts 24- and 48-bit values and mnemonics.

              
Stopping and sessions

              
Stop ends execution; Reset clears the machine and its output. Disconnecting loses the session and uploaded files: load the job again after reconnecting. Use separate browser tabs for parallel runs.

              
Interface language

              
Switch between Russian and English in the top bar. Your selection is saved in this browser. It does not change source code, mnemonics or guest program output.

Programs from the example catalog

            

            
.dub programs use the Job settings. JSON presets in web-jobs set the program, mode, speed and toggles; machines contains Supervisor images. Select JSON here, upload a file, or edit it in Editor. Debug starts paused.
