# Braille font

`NotoSansSymbols2-Braille.ttf` is the U+2800–U+28FF subset supplied by Google Fonts for Noto Sans Symbols 2. It is bundled locally so punch cards use the same glyphs and cell widths without a network connection or a system font fallback.

Source: https://fonts.google.com/noto/specimen/Noto+Sans+Symbols+2
