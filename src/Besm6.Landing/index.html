01 / Машина своей эпохи

Большая электронная.
Большие задачи.

БЭСМ-6 создавали для того, чтобы считать то, что прежде казалось слишком сложным.

Разработанная в ИТМиВТ под руководством Сергея Лебедева, машина прошла государственную приёмку в 1967 году. Она стала инструментом научных расчётов — в исследовательских институтах и вычислительных центрах.

Транзисторная логика, ферритовая память и совмещение этапов выполнения команд. За рядами тумблеров и ламп стояла архитектура, которую интересно изучать и сегодня.

02 / Внутри БЭСМ-6

48 бит.
Целый мир внутри.

Слова, команды и память —
настоящая архитектура большой машины.

01 — Данные

Одно слово. Две команды.

48 разрядов для данных или двух 24-битных команд. Например: загрузить число из ячейки 01000 в сумматор и прибавить число из ячейки 01001.

0010 10000004 1001
СЧ 0,01000
Левая команда · 24 битаСЛ 0,01001
Правая команда · 24 бита

Код команд и адреса — в восьмеричной системе.

02 — Память

Память, которую можно увидеть.

Базовые 32 768 слов — это 192 КиБ полезных данных. Каждый бит хранился в крошечном ферритовом сердечнике.

03 — Печать

Результаты на бумаге.

Алфавитно-цифровое печатающее устройство АЦПУ-128 печатало результаты расчётов и листинги программ. В симуляторе этот вывод можно читать во вкладке «Печать / Printer».

03 / Besm6.Net

История оживает,
когда работает код.

Исследуйте БЭСМ-6 через программы.
Без установки на ваш компьютер.

Задание для системы «Дубна».dub
*name hello
*ftn
      PROGRAM HELLO
      PRINT 10
      STOP
   10 FORMAT('HELLO, WORLD!')
      END
*execute
*end file

Открыть симулятор ↗
  1. 01

    Откройте консоль

    Дождитесь статуса Connected: для вас будет создана отдельная сессия.

  2. 02

    Выберите программу

    Во вкладке Examples найдите fortran.dub и нажмите «Загрузить в машину / Load into machine».

  3. 03

    Нажмите «Пуск / Run»

    Для непрерывного выполнения выберите «Полный запуск / Full run». Результат появится во вкладке «Печать / Printer».
