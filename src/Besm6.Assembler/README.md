# Besm6.Assembler

Исходники сгруппированы по ответственности внутри одной DLL.
Пространства имён и публичные контракты сохраняются.

| Папка | Назначение |
|---|---|
| `Api/` | контракты и результаты сборки |
| `Assembly/` | сборка программ и диалекты |
| `Detection/` | выбор диалекта |
| `Disassembly/` | дизассемблирование |
| `Parsing/` | лексика, разбор и символы |

[Границы проектов и владельцев исполнения](../../docs/source-layout.md).
