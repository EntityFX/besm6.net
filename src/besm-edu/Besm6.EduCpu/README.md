# Учебный демонстратор процессора БЭСМ-6 (C#)

Самостоятельная учебная модель **частичной** архитектуры БЭСМ-6: 48-разрядное
машинное слово, 32 768 слов памяти, учебный набор из 12 команд (включая вычитание
и умножение), аккумулятор, 16 индекс-регистра, условный и безусловный переходы,
стоп и трассировка.

Это **не** полная реинкарнатация машины: список сознательных упрощений — в конце файла.

Внешних NuGet-зависимостей в основном проекте нет (только BCL, net8.0).

## Запуск

```text
dotnet run --project src/besm-edu/Besm6.EduCpu            # выполнить программу целиком
dotnet run --project src/besm-edu/Besm6.EduCpu -- --step  # шаг за шагом (Enter между командами)
dotnet run --project src/besm-edu/Besm6.EduCpu -- --max-steps 3   # ограничить число шагов
dotnet run --project src/besm-edu/Besm6.EduCpu -- --dump 0100 0111  # после выполнения — дамп памяти
dotnet run --project src/besm-edu/Besm6.EduCpu -- --help  # справка
```

Обычный запуск:

1. печатает заголовок, адрес входа (восьмерично) и ожидаемый результат;
2. печатает листинг команд и данных;
3. выполняет программу до `STOP`;
4. печатает трассу: номер шага, адрес с позицией L/R, команда, исполнительный
   адрес, аккумулятор до/после, следующая позиция, эффект;
5. по `--dump START END` печатает «ДАМП ПАМЯТИ» — финальное содержимое
   диапазона адресов (восьмеричные адреса, включительно);
6. печатает итог (причина останова, число шагов, содержимое ячейки 0110).

Ошибки (диагностическая ошибка машины, превышение лимита шагов, неверные
аргументы) печатаются в stderr, код возврата ненулевой. `--help` печатает
справку и завершается с кодом 0, не запуская процессор.

## Тесты

```text
dotnet test src/besm-edu/Besm6.EduCpu.Tests
```

49 тестов: машинное слово (включая вычитание и умножение), кодирование/декодирование
команд, память, смена L/R, перенос 02→15, индексная адресация, все 12 команд,
циклический перенос СЛЦ, поведение STOP, лимит шагов, неизменность состояния после
диагностической ошибки, итог встроенной программы, детерминированность
трассы, дамп памяти и парсинг восьмеричных адресов, суммарный предел 1000 строк
основного кода.

## Словарь команд (учебный поднабор)

| Код | Мнемоника | Действие |
|-----|-----------|----------|
| 000 | ATX / ЗП | память[адрес] = аккумулятор |
| 001 | SUB / ВЫЧ | аккумулятор = аккумулятор − память[адрес] (по модулю 2^48) |
| 002 | MUL / УМН | аккумулятор = (аккумулятор × память[адрес]), младшие 24 бита операндов |
| 010 | XTA / СЧ | аккумулятор = память[адрес] |
| 011 | AAX / И | аккумулятор &= память[адрес] |
| 012 | AEX / НТЖ | аккумулятор ^= память[адрес] |
| 013 | ARX / СЛЦ | циклическое сложение аккумулятора и слова памяти |
| 015 | AOX / ИЛИ | аккумулятор \|= память[адрес] |
| 0240 | VTM / УИА | M[регистр] = 15-разрядное поле адреса |
| 0260 | UZA / ПО | переход, если аккумулятор == 0 |
| 0300 | UJ / ПБ | безусловный переход |
| 0330 | STOP / СТОП | останов процессора |

Короткий формат: 4 бита регистра, 6 бит кода, 12 бит адреса + признак X
(дополняет адрес 111, как в настоящей БЭСМ-6: `070000 | адрес`).
Длинный формат: 7 бит кода (с признаком формата), 15 бит адреса.

Коды операций собраны в перечисление `Op` (файл `Op.cs`) — значения соответствуют
восьмеричным кодам; это упрощение по сравнению с настоящим декодером.

## Сознательные упрощения модели

- **ARX реализован как циклическое сложение 48-разрядных слов**
  (перенос из 49-го разряда прибавляется к младшему), а не как сложение
  вещественных чисел, как это делал «СЛЦ» на реальных данных БЭСМ-6.
- **SUB (вычитание) — по модулю 2^48** (двоичное дополнение), а не как
  вычитание вещественных чисел; перенос отбрасывается.
- **MUL (умножение) — учебное**: перемножаются младшие 24 бита обоих операндов,
  в аккумулятор записываются младшие 48 бит произведения. Это не умножение
  48-разрядных вещественных чисел настоящей БЭСМ-6.
- **UZA проверяет только `ACC == 0`**; условные переходы с регистрами
  (режимы RAU/RAZ) не моделируются.
- **M0 при чтении всегда 0**; запись в M0 не имеет эффекта (в модели M0
  просто не используется как назначение, кроме чтения).
- **Нет** вещественной арифметики, сдвигов, прерываний, УУК,
  признаков/служебных битов команд, банков памяти и временных моделей.
- Переход всегда к **левой** половине целевого слова.
- Диагностические ошибки (широта полей, чужой код операции) бросают
  исключение **до** изменения состояния машины — это упрощение, а не
  историческое поведение.

Всё перечисленное — ограничения учебной модели, а не утверждения об
архитектуре настоящей БЭСМ-6; исторические детали — в `book/` и `ref/`.
