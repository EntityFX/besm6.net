## 3. Проверка ключевых замечаний рецензий

- Время счёта БЭСМ-6 измерено дифференциально (`tools/benchmark_ai_besm.py`):
  регрессия по N = 1…6, вклад трансляции и загрузки исключён; вывод отделён
  «тихим» вариантом программы. Регулярное выражение удаления `PRINT` исправлено —
  теперь оно удаляет и `if (...) print` со вложенными скобками, а сценарий
  проверяет, что «тихий» вариант ничего не печатает.
- Счётная часть Фортрана измерена внутри процесса (`system_clock`, внешняя
  подпрограмма, `-O0` для исключения свёртки детерминированных задач); полное
  время процесса измерено на `-O2`. Операторы `PRINT` (включая `if (...) print`)
  из замеряемой подпрограммы удаляются полностью.
- Полное время Python измерено реальным запуском процесса, а не сложением старта и
  функции; старт измерен отдельно.
- Указаны ОС и версии (Windows 10, .NET SDK 10.0.403, CPython 3.14.10, GNU Fortran
  16.2.0); разрядность `REAL` описана (24/40/53 бита).
- Раздел 1.1 исправлен: IBM System/360 Model 85 — первичный источник Liptay (1968)
  с DOI; четырёхразрядное поле модификатора; мониторная система «Дубна»; серийный
  выпуск 1968–1987; описание буферной памяти следует книге [4], а в модели времени
  она представлена иначе (8 + 8 + 8 записей), что оговорено в тексте.
- Модель времени описана как подгонка к одному опорному значению; доля `EXP` в
  счёте MLP XOR (≈64 %, с учётом обоих коэффициентов 1,769 и 0,671) и темп команд/с
  (1,3–1,6 млн, по согласованным парам команд и времени) обсуждаются явно.
- Список литературы содержит 21 опубликованный источник по порядку первого
  упоминания; файлы репозитория вынесены в отдельный список артефактов.

## 5. Остаточные ограничения

- `original` — калиброванная статистическая модель, а не физическая БЭСМ-6.
- Счётная часть Фортрана измерена при `-O0` (верхняя граница); при `-O2` часть
  детерминированных задач свёртывается компилятором.
- Результаты относятся к одному хосту (Xeon E3-1230 v6, Windows 10) и одному набору
  учебных задач.
- `ai-comparison.pdf` соответствует предыдущей редакции и должен быть регенерирован
  из `ai-comparison.md` (например, pandoc) после внесения правок.
