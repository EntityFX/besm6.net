# Этап 5: управляющие разряды деления

Срез:10 октября2026, база9715fd5. Добавлен `DivisionControl`: таблица4.4 ТО-3,
предыстория действия и полутактовая граница появления основного остатка.
Это часть физической последовательности; полное аппаратное время CPU ещё
не реализовано. Обычный Dubna использует прежний интерпретатор.

Выбор по двум старшим разрядам переносов и трём разрядам суммы учитывает
знак делителя и предыдущее сложение. Четыре неопределённые комбинации дают
один сдвиг; он снимает память предыдущего сложения. Первоначально эта память
установлена только для отрицательного делимого и положительного делителя.
Входные разряды должен предоставить будущий физический сумматор.

Контрольные разряды появляются на0,5 такта раньше соответствующих основных
рядов. Узел регистрирует эту границу в календаре; следующая выборка возможна
через полный такт. Снимок достигнутой границы не содержит полных рядов остатка.
Стадии АУ не выдают ИЗОП до уже запрошенной границы. Завершение закрывает
узел, общее гашение отменяет только его события, повторный запуск создаёт
новую предысторию. Гостевой результат вычисляется общим алгоритмом деления.
