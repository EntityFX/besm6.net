# Этап 5: первый блок аппаратного времени

Дата: 10 октября 2026 года. Базовый коммит: `d92d855`.

Добавлены отдельные наносекундные типы, детерминированный календарь
событий и резервирование явно заданных ресурсов. Таблица источника
сохраняет отдельные времена УУ и диапазоны АУ для 47 команд;
статистическое среднее не используется как длительность исполнения.
Сканы проверены визуально, хеши закреплены в
[аудите](hardware-time-source-audit.json).

Новая инфраструктура пока не подключена к CPU, памяти или устройствам.
Семантика команд, существующий `SimulationClock`, таблица `Besm6Timing`
и ограничение темпа original сохранены. Аппаратные правила арбитража,
готовности результатов и задержки конкретных операндов не предполагаются.

## Проверки

Release: **2574 прошли, 0 ошибок, 3 прежних пропуска**.
В том числе 64 новые проверки аппаратного времени и **397/397 активных
CERN-случаев**, без изменения эталонов или фильтров. Fast golden:
**3/3**, сравнения включены.

```powershell
dotnet test Besm6.sln -c Release --no-restore --logger "trx;LogFileName=stage5-foundation-full.trx"
python tools/run_all_examples.py --dll src/Besm6.Cli/bin/Release/net8.0/besm6.dll --suite fast --output tests-run/stage5-foundation-golden
```

Проверены одинаковое время событий, отменённые/чужие токены,
вложенное scheduling, запрет вложенного продвижения, сохранение причины
ошибки callback и продолжение после ошибки; переполнение не меняет
резервирование. Независимые численные векторы проверяют наносекундные
значения и отсутствие придуманных значений для неизвестных команд.
Синтетическое перекрытие ресурсов проверяет календарь, а не историческую
машину.

[JSON](hardware-time-foundation-results.json) содержит исходы всех
397 CERN-случаев и SHA256 локальных TRX; [CSV](hardware-time-foundation-results.csv)
содержит сводку проектов. Заголовки TRX с идентификаторами хоста не включены.

Новый замер скорости в этом блоке не проводился: горячий путь CPU
не изменён, добавленные типы не используются действующим исполнением.
Прирост скорости или соблюдение новых аппаратных задержек не заявляются.
