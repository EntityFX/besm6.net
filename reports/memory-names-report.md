# Имена компонентов памяти

По запросу пользователя из имён API, тестов и файлов удалён суффикс года.
Режим теперь называется `MemoryModel.Buffered`; используются
`PhysicalMemory`, `PageAssignment`, `BufferedMemory`, `BufferedMemoryBackend`,
`MemoryAddressKind`, `MemoryAccessKind`, `ResolvedMemoryAddress`,
`MemoryBufferEntry` и `MemoryProtectionException`.

Это переименование публичного API. Старые типы и значение перечисления
с суффиксом года не оставлены как aliases; внешнему коду потребуется
перекомпиляция и замена имён. Значения режимов, размеры, правила памяти,
формулы времени и обработчики команд не изменены.

Документы также переименованы:
[память](../docs/besm6-hardware-memory.md),
[буферы](../docs/besm6-memory-buffers.md),
[регистры](../docs/besm6-memory-registers.md).
Годы редакций источников сохранены. JSON/CSV прежних измерений сохраняют
исходные имена и пути на момент соответствующего коммита: это исторические
артефакты, их контрольные суммы и измерения не переписаны.

Release и CERN проверены повторно; численные итоги закреплены в
[JSON](memory-names-results.json). Golden: 3/3 с прежними счётчиками.
Новые результаты производительности не заявляются.
