# Этап 5: образование частного

База31e09c8. Реализованы положительная и отрицательная составляющие частного,
42 явных сдвига и сигналы коррекции по ТО-3 §4.16. Вычитание делителя записывает
положительную цифру, сложение — отрицательную. При одном сдвиге обе составляющие
сдвигаются без новой единицы. Дополнительный разряд отделяется при образовании.

Если первые основные разряды обеих составляющих нулевые, коррекции нет.
Иначе дополнительный разряд положительной составляющей задаёт+1 при единице
и−1 при нуле. Коррекция−1 подавляет единицу перехода обратного кода в дополнительный,
коррекция+1 выдаёт отдельную единицу. Это входы будущего физического сумматора;
знаковый результат служит логическим эталоном, не публикуется в CPU.
Сдвиг через DivisionControl получает явный импульс; повтор для одной выборки
отклоняется. Гашение/повторный запуск не переносят составляющие в новое деление.
Общий алгоритм Dubna сохранён.

Проверки:2715 passed,0 failed,3 прежних skipped; Runtime533, Processor1552.
