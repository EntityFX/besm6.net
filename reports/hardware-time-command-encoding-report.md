# Формирование проверенных команд АУ общим CPU

10 октября2026. Принятая база178a04b; координатор владельцев отдельно залит a68130f.
Подблок6 оценочных часов, не измеренное время работы агента.

ТО-3 таблица1.1, листы4/5, закрепляет программный и аппаратный коды для
одиннадцати операций. ArithmeticCommandEncoding формирует17-разрядное слово:
операция в15–10, непосредственный источник в9 с семью битами адресного
операнда, либо явно выделенная ячейка БРУС. Признаки4/5/6 означают БРЧ,
специальные регистры и пультовые внешние устройства; без признаков — БРЗ.
Непосредственный операнд использует общий resolver C/индекса/15-разрядного
адреса, не продвигая K/половину и не меняя регистры. Повторный приём проверяет
сохранённое слово; изменение C/M, влияющее на него, даёт конфликт модели до
эффектов CPU. Типизированный вход проверяет код/операнд/буферные признаки.

Обработчики, A/Y, округление, стек, исключения и диагностика остаются общими.
19 новых случаев включают независимые полные слова, обе половины и пять
режимов, стековое деление, перенос C/индекса через границу адреса, группы
буферов и отказ неверному входу без изменения CPU. Старые непосредственные
фикстуры с нулевой операцией заменены правильными034/035; проверки не ослаблены.
2898 тестов девяти проектов, Runtime658/658, CERN397/397, golden3/3;
три прежних пропуска. Число включает две отдельные проверки координатора.

Границы: ячейку пока назначает вызывающий узел, аппаратный маршрут её данных
не интегрирован. Синтетическая raw uint перегрузка сохранена для тестов фаз.
РПК, прямой ПВР и ИЗОП задаются явно; автоматические управляющие цепочки,
физические причины/УУ, перекрытие, MRAM/устройства и полный аппаратный профиль
остаются в работе. Функциональный CERN не является аппаратным ОС-гейтом.

Release, последовательные серии, фиксированный DATE*,1 прогрев+5 измерений;
Dhrystone0/5000/10000, MPMFLOPS0/1/2/3,9000×30. База сохранена до сборки и
сверена по четырём DLL с принятой серией; RunLoaded и CLI измерены отдельно.
