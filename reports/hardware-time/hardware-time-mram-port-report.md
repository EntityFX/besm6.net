# Общий порт MRAM и календарь банков

Порт аппаратной модели подключён к тому же PhysicalMemory машины и её наносекундному календарю.
Чтение и запись имеют общую очередь каждого из восьми банков; разные банки работают независимо.
Выдача данных и освобождение банка разделены. Отмена убирает непереданный результат,
не сокращая начатого цикла. Callback может добавлять/отменять запросы; ошибка callback
не откатывает уже опубликованную запись и не теряет будущую очередь.

Минимум2 мкс и приблизительный возврат чтения0,9 мкс закреплены ранее по ТО-4 §§1.1–1.2.
FIFO, выборка при начале/возврате чтения и момент видимости записи — явные параметры
логического приближения. Они не названы электрическими правилами реальной машины.
Буферы, mapping/remap во время запроса, выборкаCPU и DMA ещё не подключены.

Проверки: 2993 теста Release, CERN397/397, golden3/3, три прежних пропуска.
10 новых случаев проверяют FIFO, независимость банков, видимость, контрольные разряды,
отмену до/после начала, callback, границы и сохранение порта при ResetCpu.
Ранний тест отмены обращался к уже завершённому запросу; стенд исправлен,
поместив отменяемый запрос за занятый банк. Правила контроллера не ослаблялись.

Худшая регрессия основных заданий RunLoaded 3.115%, CLI 2.259%; допуск5%.
Основные задания: Dhrystone5000/10000 и MPMFLOPS1/2/3. Все baseline-серии сохранены.
Калибровочный mp0 CLI показал6,62% замедления (0,406–0,518 с для current);
эта серия не исключена из данных. Причина разброса не установлена.
Максимальная ошибка original 6.463 мс.
Последовательные Release-прогоны: один прогрев, пять измерений, fixedDATE*, baseline,
отдельные RunLoaded/CLI, проверка original на Dhrystone10000 и MPMFLOPS3.
Функциональный корпус проверяет совместимость; аппаратная ОС ещё не проверена.

Принято8 оценочных часов памяти: остаток130→122 ч; MRAM32 ч остаётся.
