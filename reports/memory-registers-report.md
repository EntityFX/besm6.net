# Этап 3: формат РП и РЗ

По таблицам ТО-8, редакция 1–67, листы 106–109 добавлены
`ImportAssignmentGroup` и `ImportProtectionGroup` в `PageAssignment`.
[Спецификация и источник](../docs/besm6-memory-registers.md).

РП получает четыре пятиразрядных номера страниц и четыре дополнительных
бита расширения 64K. Компонент 32K отклоняет дополнительный бит целиком,
до изменения таблицы. РЗ принимает выбранный байт из разрядов 21–28
сумматора и сохраняет другие группы защиты.

Добавлено **227 проверок**, включая каждый значимый разряд, буквальные
контрольные коды, атомарный отказ, неиспользуемые поля и сохранение соседних
групп. Release: **2188 passed, 0 failed, 3 прежних пропуска**;
CERN: **397/397** активных случаев; golden: **3/3** с прежними счётчиками
инструкций. Сравнения и эталоны не ослаблены.

```powershell
dotnet test Besm6.sln -c Release --no-restore --logger 'trx;LogFileName=stage3-register-format.trx'
python tools/run_all_examples.py --dll src/Besm6.Cli/bin/Release/net8.0/besm6.dll --suite fast --only algol,bemsh,name --limit 20000000 --timeout 120 --output tests-run/stage3-register-format-golden
```

Импорт пока вызывается только из API хоста и тестов. Исполнение ЗпР,
пересылка БРЗ, привилегии и аппаратное состояние при прерывании не реализованы.
Подключение математической адресации к CPU остаётся следующим блоком после
проверки аппаратных тегов БАЗ/БАС и протокола смены приписки.

Производительность в этом изменении повторно не измерялась: активные пути
выборки команды, исполнения, буферов и RunLoaded побайтово совпадают
с 83177cd после нормализации переводов строк; новые методы из них не вызываются.
Результаты предыдущей серии остаются в [отчёте моделей памяти](memory-models-report.md).
Новый выигрыш или новый результат бенчмарка не заявляется.

[JSON](memory-registers-results.json) и [CSV](memory-registers-results.csv)
содержат обезличенные результаты. Полные TRX остаются в игнорируемых каталогах.
