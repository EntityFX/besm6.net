## Исправление при первоначальной верификации

В разделах 2.3 и 5 обеих версий граница стандартной ошибки уточнена:
**2,5 % → 2,51 %** (два вхождения в каждом файле).

Максимальная относительная стандартная ошибка относится к решающему пню:

```text
compute_seconds = 0.003146546085714265 s
compute_se      = 0.00007893665575298272 s
100 × compute_se / compute_seconds = 2.508676294663713 %
```

Значение округляется до 2,5 % при одном знаке после запятой, однако для строгого
утверждения «не превышает» / «не более» эта граница немного занижена.
Исправленная граница 2,51 % покрывает фактический максимум.

## Ограничения проверки

Для старого значения времени пустого задания **0,711 с** исходный пакет
и отдельный первичный лог не найдены. Значение присутствует в истории статьи,
но независимо подтвердить его по сохранённым измерениям нельзя.
Новый контрольный минимальный пакет `PROGRAM EMPTY; STOP; END` дал
**0,521337521 с**; тождественность этого пакета старому не установлена,
поэтому заменять одно значение другим некорректно. Число 0,711 с в статье
оставлено без изменения и не используется для вычисления таблиц 1–4.

Проверка не является подтверждением исторических аппаратных задержек,
биографических дат или библиографических реквизитов. Время современных
процессов проверено по сохранённым измерениям, без новой измерительной серии
на потенциально изменившемся хосте.

### Уточнения к числам из замечаний

- Текущий JSON содержит, например, `instructions_per_pass = 47002.4` для
  перцептрона и `19741.2` для k-NN, а не 47 075 и 19 975 из замечания.
  Таблица 1 сверена с текущим первичным файлом и не заменялась числами
  из другой редакции.
- Медиана БЭСМ-6/Fortran для времени счёта равна **8176,113356861188**,
  то есть **8,2·10³**. Число **8695** — значение строки генетического алгоритма,
  а не медиана. Формулировка статьи сохранена.
- Относительная стандартная ошибка счёта: k-NN **0,971020 %**, решающий пень
  **2,508676 %**, мини-шахматы **2,101926 %**. Соответствующие ошибки наклона
  варианта с печатью: **0,478964 %**, **1,280485 %**, **1,484345 %**.
  Значения восстановлены по сохранённым разностям всех шести измерений;
  объяснять старые 10–19 % только включённой печатью по этим данным нельзя.
- Время процесса CPython для генетического алгоритма в JSON равно **0,06655 с**,
  то есть **66,55 мс**. Десятичное округление до одного знака даёт **66,6 мс**;
  исходные JSON и отношения, рассчитанные из неокруглённых времён, не менялись.
- Выражение «около 1 млн. одноадресных операций в секунду» приведено дословно
  в [главе I, § 1 книги Салтыкова и Макаренко](../book/fortran-1976/01-besm6.md).
  Там отдельно указаны времена операций с плавающей запятой; смешивать
  общий темп команд и FLOPS при правке статьи некорректно.
