# Проверка читаемости

## Вывод

**Читаемость OCR-текста недостаточна для книги в целом.** Markdown структурно исправен, однако в разделах II–IV сохраняются многочисленные искажения обычных слов, технических сокращений, индексов и границ предложений. Для надежного чтения необходима ручная сверка со сканами.

Вручную сверены раздел I, таблица 2.1 и таблицы старшинства на рис. 4.3–4.4. Добавлены 11 диаграмм Mermaid; исходные изображения сохранены для сверки. Для сложных схем приведено функциональное представление с явно указанными упрощениями. Проверка структуры Markdown не подтверждает правильность технического содержания.

## При сборке

Четыре раздела объединены в один файл. Внесено 170 однозначных замен обычных слов по явному списку; восстановлено 289 стыков разорванных абзацев. Сигналы и числа по словарю автоматически не исправлялись.

## Диаграммы Mermaid

В единый Markdown включены рис. 2.1–2.8 и 4.5–4.7. Две ранее существовавшие диаграммы сохранены. Для временных и сложных сигнальных схем отмечены ограничения: масштаб времени, двоичные маски и поразрядные цепи не заменены догадками. Точность всех сигнальных условий существовавших диаграмм пока не подтверждена.


## Текущая проверка после переноса диаграмм

Все 11 блоков Mermaid разобраны и отрисованы движком Mermaid 11 без ошибок синтаксиса. Просмотрены изображения отрисовки, исправлены ошибки экранирования подписей. Все ссылки на исходные чертежи существуют. В итоговой папке только два MD-файла и 11 PNG.

В текущей прозе без кода Mermaid и формул проверено 6794 словоупотреблений длиной от четырех букв; найдено 75 словарных кандидатов (29 различных форм). Это не процент OCR-ошибок. Примеры и числа в предыдущих разделах отчета относятся к первому черновику и могут уже не встречаться в текущем тексте.

Полная сверка всех булевых условий со сканами не завершена. Рис. 2.1–2.4, 2.7–2.8, 4.6–4.7 содержат оговоренные упрощения; для проверки сигналов следует использовать исходные чертежи.
