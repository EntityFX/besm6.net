# Занятие 8. Минимальный процессор БЭСМ-6

Продолжительность: 2–3 часа.

## Цель

Соединить слово, декодер, АЛУ, память и системные сервисы в воспроизводимый
цикл исполнения небольшого набора команд.

## Материалы занятия

- [Теория: интеграция компонентов и атомарный шаг процессора](THEORY.md)
- [Практика: `Step()`, `Run()` и итоговая программа](PRACTICE.md)

## Подготовка

- завершить занятия 1–7 или использовать выданные преподавателем компоненты;
- подготовить таблицу команд итоговой программы;
- повторить поиск первой отличающейся строки трассы.

## Результат

Минимальный процессор, итоговая программа, ограниченное исполнение,
воспроизводимая трасса и регрессионный тест внесённой ошибки.
