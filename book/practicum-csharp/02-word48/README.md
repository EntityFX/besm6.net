# Занятие 2. 48-разрядное машинное слово

Продолжительность: 2–3 часа.

## Цель

Понять позиционные системы счисления и разные интерпретации одного машинного
слова. Реализовать неизменяемый `Word48`.

## Материалы занятия

- [Теория: двоичная и восьмеричная запись, целый и плавающий форматы](THEORY.md)
- [Практика: реализация и тестирование `Word48`](PRACTICE.md)

## Подготовка

- повторить степени двойки и дополнительный код;
- открыть [`Word48`](../../../src/besm6.net/Core/Word48.cs) только как справочник
  по контракту, не копируя реализацию;
- подготовить бумагу для ручного перевода чисел.

## Результат

Тип `Word48`, восьмеричный парсер и форматтер, выделение командных половин,
числовые интерпретации и не менее десяти тестов.
