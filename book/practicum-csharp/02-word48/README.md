# Практическая работа 2. 48-разрядное машинное слово

Продолжительность: 2–3 часа.

## Цель

Реализовать тип, который хранит ровно 48 значащих бит и допускает несколько
архитектурных интерпретаций одного значения.

## Задание

Создайте неизменяемый тип `Word48`. Внутри разрешается использовать `ulong`,
но после каждой операции должны сохраняться только младшие 48 бит.

Реализуйте:

```csharp
public readonly struct Word48
{
    public const ulong Mask = (1UL << 48) - 1;
    public ulong Value { get; }

    public Word48(ulong value);
    public string ToOctal();
    public static Word48 ParseOctal(string text);
    public long ToSignedInt64();
    public static Word48 FromSignedInt64(long value);
    public double ToDouble();
    public static Word48 FromDouble(double value);
    public uint LeftInstruction { get; }
    public uint RightInstruction { get; }
}
```

Для принятой в эмуляторе числовой модели биты 47–41 содержат порядок со
смещением 64, а биты 40–0 — знаковую мантиссу в дополнительном коде.

## Обязательные тесты

1. Конструктор обрезает биты старше 47-го.
2. Восьмеричная строка содержит ровно 16 цифр.
3. Проверяются `0`, `1`, `2^47 - 1`, `-1` и `-2^47`.
4. Некорректная восьмеричная цифра отклоняется.
5. Проверяется преобразование нескольких степеней двойки.
6. Выполняется цикл `double → Word48 → double` с заданной погрешностью.
7. Из известного слова правильно выделяются две 24-разрядные команды.
8. Равенство и хеш-код зависят только от 48 значащих бит.

## Эксперимент

Возьмите одно слово и последовательно измените:

- один бит порядка;
- знаковый бит мантиссы;
- младший бит мантиссы;
- один бит левой команды.

Составьте таблицу влияния каждого изменения на все доступные интерпретации.

## Результат работы

## Контрольные вопросы

1. Почему для хранения 48 бит удобно использовать `ulong`, но нельзя отдавать
   его значение без маскирования?
2. Почему восьмеричная система удобна для БЭСМ-6?
3. Как выполняется знаковое расширение 48-разрядного целого до `long`?
4. Кто определяет смысл слова: память или текущая операция?
