# Практика к занятию 3. Декодер двух форматов

## Результат работы

Чистый C#-декодер получает 24-разрядное значение и возвращает формат, код
операции, модификатор и основной адрес. Отдельная функция формирует
исполнительный адрес.

## Пошаговая работа

### Шаг 1. Опишите результат

Создайте `InstructionFormat` и неизменяемый `DecodedInstruction`. Включите в
результат сырую команду, чтобы трасса позволяла проверить разбор.

### Шаг 2. Ограничьте вход 24 битами

Выберите и задокументируйте политику: отклонять старшие биты исключением либо
маскировать их. Для учебной работы предпочтительно исключение, потому что оно
быстро обнаруживает ошибку вызывающего кода.

### Шаг 3. Выделите формат и поля

Сначала прочитайте форматный разряд. Затем примените маски именно выбранного
формата. Каждое поле оформите локальной переменной с говорящим именем.

### Шаг 4. Реализуйте адресный тракт

Метод `ResolveAddress` принимает основной адрес, номер M-регистра и набор из 16
значений. Для M0 поправка равна нулю. Результат ограничьте 15 адресными битами.

### Шаг 5. Декодируйте обе половины слова

Сделайте метод, который получает `Word48` и возвращает пару результатов,
используя один декодер для обеих половин.

### Шаг 6. Подготовьте ручную таблицу

Выберите не менее четырёх команд: по две каждого формата. До запуска программы
вручную подпишите поля, затем сравните с результатом модели.

## Обязательные тесты

1. Все поля нулевой команды равны нулю.
2. Каждый модификатор от 0 до 15 извлекается без искажений.
3. Граничный короткий адрес не затрагивает код операции.
4. Граничный длинный адрес содержит 15 единиц.
5. Формат определяется форматным разрядом.
6. Старшие биты за пределами 24 обрабатываются по выбранной политике.
7. M0 оставляет адрес без изменений.
8. Ненулевой M-регистр изменяет адрес.
9. Переполнение адреса обрезается до 15 бит.
10. Левая и правая команды одного слова декодируются независимо.

## Типичные ошибки

- определять формат по таблице операций;
- применять маску короткого адреса к длинной команде;
- считать M0 обычным элементом массива без соглашения;
- выполнять операцию внутри декодера;
- перепутать половины 48-разрядного слова.

## Критерии приёмки

- 4 балла — правильные поля обоих форматов;
- 2 балла — исполнительный адрес;
- 2 балла — граничные тесты;
- 2 балла — ручная таблица и объяснение этапов.
