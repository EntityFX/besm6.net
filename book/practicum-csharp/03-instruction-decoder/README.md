# Занятие 3. Декодер команд

Продолжительность: 2–3 часа.

## Цель

Научиться выделять поля короткоадресной и длинноадресной 24-разрядной команды,
не смешивая декодирование с исполнением.

## Материалы занятия

- [Теория: поля команды, форматы и исполнительный адрес](THEORY.md)
- [Практика: чистый декодер и таблица ручной проверки](PRACTICE.md)

## Подготовка

- выполнить занятие 2;
- повторить маски, сдвиги и шестнадцатеричные литералы C#;
- принести схему разрядов обоих форматов команды.

## Результат

Тип `DecodedInstruction`, декодер двух форматов, адресный тракт и набор
граничных тестов.
