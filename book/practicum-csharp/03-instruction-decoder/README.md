# Практическая работа 3. Декодер команд

Продолжительность: 2–3 часа.

## Цель

Реализовать декодирование 24-разрядной команды и формирование исполнительного
адреса без выполнения самой операции.

## Модель результата

```csharp
public enum InstructionFormat
{
    Short,
    Long
}

public readonly record struct DecodedInstruction(
    InstructionFormat Format,
    int Opcode,
    int Register,
    int RawAddress,
    int EffectiveAddress);
```

## Задание

Реализуйте класс `InstructionDecoder` с методами:

```csharp
DecodedInstruction Decode(uint instruction, ReadOnlySpan<ushort> modifiers,
                          ushort temporaryModifier = 0);

(DecodedInstruction Left, DecodedInstruction Right)
    DecodeWord(Word48 word, ReadOnlySpan<ushort> modifiers);
```

Алгоритм должен:

1. оставить только 24 младших бита команды;
2. выделить четырёхбитный номер регистра-модификатора;
3. определить короткий или длинный формат;
4. выделить код операции;
5. расширить короткий адрес нулями либо единицами;
6. добавить значение M-регистра;
7. добавить временный модификатор MOD;
8. оставить 15 младших бит исполнительного адреса.

Декодер не должен обращаться к памяти и изменять процессор.

## Обязательные тесты

- короткая команда с положительным адресом;
- короткая команда с расширением адреса единицами;
- длинная команда;
- M0 как отсутствие модификации;
- ненулевой M-регистр;
- переполнение 15-битного адреса;
- применение MOD ровно к одной команде;
- разные команды в левой и правой половинах слова;
- неизвестный код возвращается как число и не превращается в `NOP`.

## Практический эксперимент

Выберите пять команд разных групп. Для каждой вручную заполните таблицу полей,
затем сравните результат с вашим декодером и дизассемблером проекта.

## Результат работы
