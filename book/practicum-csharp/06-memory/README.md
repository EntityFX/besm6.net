# Практическая работа 6. Память и адресный тракт

Продолжительность: 2–3 часа.

## Цель

Реализовать память на 32K 48-разрядных слов и исследовать влияние расслоения
памяти на последовательность обращений.

## Архитектурная модель

Для лабораторной используется текущая модель репозитория:

- 32 768 слов;
- 15-битный адрес;
- восемь банков памяти;
- `bank = address % 8`;
- `offset = address / 8`.

Временная модель является учебной и должна быть явно отделена от функциональной
корректности чтения и записи.

## Задание

Реализуйте `BankedMemory : IMemory`, которая:

1. хранит данные в восьми отдельных массивах;
2. читает и записывает `Word48`;
3. отклоняет адрес за пределами памяти;
4. сообщает банк и смещение;
5. ведёт журнал операций;
6. моделирует занятость каждого банка до определённого такта;
7. возвращает момент завершения запроса.

Пример записи журнала:

```text
T=0012 READ  A=00107 BANK=7 OFFSET=0010 READY=0014 VALUE=...
```

## Эксперименты

Сравните три последовательности:

1. `0, 1, 2, 3, ...` — последовательный доступ;
2. `0, 8, 16, 24, ...` — повторное обращение к одному банку;
3. псевдослучайная последовательность с фиксированным seed.

Для каждой вычислите число конфликтов банков и модельное время завершения.

## Обязательные тесты

- размер памяти равен 32768 словам;
- начальное значение каждой ячейки равно нулю;
- чтение возвращает ранее записанное слово;
- соседние адреса попадают в разные банки;
- адреса с шагом 8 попадают в один банк;
- выход за диапазон приводит к диагностируемой ошибке;
- журнал не изменяет функциональный результат;
- повтор эксперимента даёт идентичный журнал.

## Результат работы

- модель расслоенной памяти;
- журнал обращений;
- сравнительная таблица трёх последовательностей;
- график или временная диаграмма занятости банков.

## Контрольные вопросы

1. Почему адрес БЭСМ-6 указывает на слово, а не на байт?
2. Как расслоение повышает пропускную способность?
3. Почему шаг, равный числу банков, создаёт конфликт?
4. Чем пропускная способность отличается от задержки одного обращения?
