# Практика к занятию 6. Расслоенная память

## Результат работы

Память на 32 768 слов с проверкой адреса, восемью банками, модельным временем и
журналом обращений.

## Пошаговая работа

### Шаг 1. Реализуйте функциональное хранение

Создайте массив `Word48[32768]`, методы `Read` и `Write`. Сначала добейтесь
корректности без временной модели.

### Шаг 2. Проверяйте адрес

Отклоняйте отрицательное значение и адрес выше `77777₈` собственным
диагностическим исключением до обращения к массиву.

### Шаг 3. Вычисляйте банк и строку

Используйте `bank = address & 7` и `row = address >> 3`. Проверьте формулы
ручной таблицей для нескольких адресов.

### Шаг 4. Добавьте модельное время

Для каждого банка храните `BusyUntil`. Запрос начинается в максимуме времени
поступления и готовности банка. Не используйте реальные задержки.

### Шаг 5. Ведите журнал

Каждая запись содержит адрес, банк, операцию, время поступления, начала и
завершения. Журнал возвращайте только для чтения.

### Шаг 6. Проведите три эксперимента

Сравните последовательные адреса, адреса с шагом 8 и случайную
последовательность. Для каждой вычислите итоговое модельное время.

### Дополнительный шаг. Страницы

Добавьте функции номера страницы и смещения для страницы размером 1024 слова.

## Обязательные тесты

1. Записанное слово читается без изменения.
2. Чтение не изменяет память.
3. Граничные адреса 0 и `77777₈` допустимы.
4. Адрес за границей отклоняется до доступа к массиву.
5. Адреса 0–7 попадают в разные банки.
6. Адреса 0 и 8 попадают в один банк и разные строки.
7. Разные банки могут начать запрос одновременно.
8. Второй запрос одного банка ожидает `BusyUntil`.
9. Журнал сохраняет порядок и все времена.
10. Страница имеет 1024 последовательных смещения.

## Типичные ошибки

- смешивать банк и страницу;
- использовать остаток от 7 вместо 8;
- моделировать микросекунды реальной задержкой;
- менять память до полной проверки запроса;
- возвращать изменяемый список журнала.

## Критерии приёмки

- 4 балла — хранение и адресация;
- 2 балла — банки и время;
- 2 балла — тесты конфликтов;
- 2 балла — журнал и сравнительный эксперимент.
