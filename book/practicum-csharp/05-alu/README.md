# Практическая работа 5. Арифметико-логическое устройство

Продолжительность: 2–3 часа.

## Цель

Реализовать ограниченный тракт данных ACC–RMR и показать, что команда изменяет
не только числовой результат, но и режим вычислительного устройства.

## Ограничения

За одно занятие не требуется полностью воспроизводить всю арифметику БЭСМ-6.
Обязательная часть включает логические операции, сложение целых шкал и сдвиг.
Нормализация плавающей точки выполняется по готовому каркасу либо как
дополнительное задание.

## Задание

Создайте класс `SimpleAlu` со состоянием:

```csharp
public Word48 Acc { get; private set; }
public Word48 Rmr { get; private set; }
public RauFlags Rau { get; private set; }
```

Реализуйте операции:

- загрузка ACC;
- `AND`, `OR`, `XOR`;
- подсчёт единичных разрядов;
- сложение двух 48-разрядных шкал;
- изменение знака;
- сдвиг объединённой пары ACC–RMR;
- переключение логического, аддитивного и мультипликативного режима.

Все результаты должны маскироваться до 48 бит. Сдвиг необходимо определить
для нулевого, положительного, отрицательного и граничного количества позиций.

## Обязательные тесты

- каждая логическая операция на известных битовых масках;
- сложение без переноса и с переносом за 48-й разряд;
- изменение знака нуля и отрицательного числа;
- сдвиг на 0, 1, 47, 48 и 49 разрядов;
- перенос вытесняемых битов между ACC и RMR;
- правильный режим RAU после каждой группы операций;
- неизменность входного `Word48`.

## Дополнительное задание

Реализуйте сложение чисел с плавающей точкой:

1. выделение порядков и мантисс;
2. выравнивание порядков;
3. сложение мантисс;
4. нормализация;
5. округление;
6. обработка переполнения порядка.
