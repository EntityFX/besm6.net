# Занятие 1. Обзор БЭСМ-6 и C#-эмулятора

Продолжительность: 2–3 часа.

## Цель

Понять состав вычислительной машины, командный цикл и архитектурное состояние.
Создать первую модель командной позиции и воспроизводимую трассу двух шагов.

## Материалы занятия

- [Теория: от простейшей модели машины до архитектурного состояния](THEORY.md)
- [Практика: снимок состояния и первый `Step()`](PRACTICE.md)

## Подготовка

- установить .NET 8 SDK;
- повторить классы, структуры, `record` и модульные тесты MSTest;
- просмотреть общую [структуру практикума](../README.md).

## Результат

Проект C# с неизменяемым снимком, корректным переходом между половинами
командного слова, тестами и короткой трассой.
