# Практика к занятию 7. Асинхронное устройство

## Результат работы

Детерминированный планировщик, конечный автомат устройства, контроллер запросов
и сравнение опроса с прерыванием.

## Пошаговая работа

### Шаг 1. Опишите состояния

Создайте `DeviceState` и тип результата. Для каждого состояния перечислите
допустимые команды и переходы до написания методов.

### Шаг 2. Реализуйте планировщик

Событие содержит время, порядковый номер и действие. Метод продвижения времени
выполняет все наступившие события в устойчивом порядке.

### Шаг 3. Запустите вывод

Из `Ready` сохраните данные, вычислите `CompleteAt`, перейдите в `Busy` и
зарегистрируйте событие. Из остальных состояний запуск отклоняется.

### Шаг 4. Завершите операцию

Событие переводит устройство в `Completed`, сохраняет результат и поднимает
запрос прерывания.

### Шаг 5. Подтвердите результат

Чтение возвращает результат, подтверждение снимает запрос и возвращает
устройство в `Ready`.

### Шаг 6. Добавьте контроллер

Зарегистрируйте несколько устройств, соберите запросы и выберите по явному
приоритету. Запретите повторяющиеся номера.

### Шаг 7. Сравните два сценария

Выполните одну операцию циклом опроса и одну с прерыванием. Подсчитайте шаги
процессора и постройте временную диаграмму.

## Обязательные тесты

1. Устройство начинает работу только из `Ready`.
2. До `CompleteAt` оно остаётся `Busy`.
3. В момент завершения появляется результат и запрос.
4. Подтверждение снимает запрос.
5. Повторный запуск занятого устройства отклоняется.
6. Одинаковые по времени события выполняются устойчиво.
7. Контроллер выбирает заявленный приоритет.
8. Запрещённый маской запрос сохраняется.
9. Ошибка операции не теряется до подтверждения.
10. Трасса двух одинаковых запусков совпадает.

## Типичные ошибки

- использовать реальный таймер;
- терять результат сразу после импульса готовности;
- разрешать переходы из любого состояния;
- давать устройству менять счётчик команд CPU;
- полагаться на случайный порядок словаря.

## Критерии приёмки

- 4 балла — автомат и планировщик;
- 2 балла — запрос и подтверждение;
- 2 балла — тесты порядка и ошибок;
- 2 балла — сравнение опроса и прерывания.
