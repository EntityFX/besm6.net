# Практическая работа 7. Внешние устройства и прерывания

Продолжительность: 2–3 часа.

## Цель

Реализовать асинхронное внешнее устройство и показать разницу скоростей
процессора, памяти и периферии.

## Модель устройства

Используйте конечный автомат:

```text
Ready → Start(command) → Busy → Complete → Ready
                         └────→ Error
```

Продолжительность операции измеряется модельными тактами, а не реальным
временем и не `Thread.Sleep`.

## Задание

Создайте интерфейс состояния устройства и реализуйте `AsyncTeletype`:

- принимает команду вывода символа;
- переходит в `Busy`;
- планирует завершение через `IEventScheduler`;
- по завершении добавляет символ в буфер;
- возвращается в `Ready`;
- выставляет запрос прерывания;
- отклоняет новую команду, пока устройство занято.

Зарегистрируйте устройство в `DeviceManager` по выбранному адресу. Создайте
небольшой контроллер, который записывает символы и подтверждает прерывания.

## Обязательные тесты

- после инициализации устройство готово;
- сразу после команды устройство занято;
- до нужного такта символ отсутствует в выходном буфере;
- в момент завершения символ появляется ровно один раз;
- завершение выставляет запрос прерывания;
- подтверждение снимает запрос;
- повторная команда в `Busy` даёт предсказуемую ошибку;
- два события с одинаковым временем выполняются в порядке регистрации;
- тесты не зависят от скорости компьютера и системного времени.

## Эксперимент

Сравните:

- синхронную реализацию, где `Write` сразу завершает вывод;
- асинхронную реализацию с модельным временем.

Опишите, какие состояния и ошибки скрываются синхронным вариантом.

## Результат работы

- асинхронный телетайп;
- диспетчер и планировщик событий;
- тесты состояний и прерывания;
- временная диаграмма одной операции.

## Контрольные вопросы

1. Почему нельзя моделировать аппаратное время через `Thread.Sleep`?
2. Что процессор может делать, пока устройство находится в `Busy`?
3. Чем сигнал готовности отличается от запроса прерывания?
4. Какие ошибки появляются при двух одновременных командах устройству?
