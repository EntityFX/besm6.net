# Масштабированные алгоритмы ИИ

41 детерминированное задание: четыре размера для каждого из десяти алгоритмов
и отдельный контрольный многослойный перцептрон. `l0` — малый размер, `l3` —
большой размер итогового сравнения. Исходные небольшие примеры в родительском
каталоге сохранены без изменений.

| Алгоритм | Что увеличивается | Итоговый большой размер |
|---|---|---|
| Перцептрон | Примеры, признаки, эпохи | 512 × 24, 100 эпох |
| kNN | Обучающие примеры, признаки, запросы | 1024 × 12, 128 запросов, k=3 |
| k-средние | Точки, признаки, кластеры, итерации | 512 × 16, 8 кластеров, 20 итераций |
| Наивный Байес | Примеры, признаки, классы, запросы | 256 × 16, 8 классов, 8192 запроса |
| Решающий пень | Примеры и все пороги | 1024 примера, 1023 порога, 2 направления |
| Генетический алгоритм | Популяция, поколения | 512 особей, 1024 поколения, область 0…1023 |
| Отжиг | Координаты, шаги поиска | 64 координаты, 30 000 шагов |
| Q-обучение | Состояния, эпизоды, горизонт | 128 состояний, 4000 эпизодов, до 512 шагов |
| A* | Сетка и открытый список | 45 × 45 узлов |
| Минишахматы | Разные допустимые позиции | 2048 позиций, мат в один ход |
| MLP, контроль | Размер сохранён | Сеть 2–2–1, XOR, 2000 эпох |

Это синтетические нагрузки с фиксированными бюджетами. Больший бюджет не является
утверждением об улучшении качества обучения. В минишахматах сохранены упрощённые
правила исходного примера, включая четыре ортогональных хода чёрного короля;
это не полная реализация правил шахмат.

Данные формируются циклами, а не тысячами строк инициализации. Размеры не
подгоняются под одинаковое число команд. Печать только в конце; вычислительный
участок включает генерацию данных, алгоритм и контрольные итоги.

Источник генерации: [`tools/ai_scaling_cases.py`](../../../tools/ai_scaling_cases.py).
Все окончательные прогоны выполнены на одном Linux-хосте; [результаты и методика](../../../reports/ai-scaling-linux-2026-11-23/README.md).

```bash
dotnet src/Besm6.Cli/bin/Release/net8.0/besm6.dll run \
  examples/ai/scaled/perceptron-l3.dub \
  --speed original --stats --guest-clock --no-wall-clock
```

В SIMH/ДИСПАК для основного контроля нужна карта **`*FORTRAN`**, а не `*FTN`:
последняя выбирает другой транслятор. Тело программы на Фортране при этом не меняется.
