# Простые алгоритмы ИИ на БЭСМ-6

Одиннадцать небольших примеров на Фортране для системы «Дубна». Каждый пример
самодостаточен, печатает результат и проверен на эмуляторе `besm6`
(Release `net8.0`).

## Запуск

```bash
cd /home/entityfx/projects/besm6.net
DLL=src/Besm6.Cli/bin/Release/net8.0/besm6.dll

for f in examples/ai/*.dub; do
  echo "=== $f ==="
  dotnet "$DLL" run "$f"
done
```

Все примеры укладываются в несколько миллионов инструкций и выполняются
за доли секунды — около 1 секунды на пример в режиме `max`.

## Ограничения Фортрана «Дубны»

Примеры написаны в стиле FORTRAN 66, без блочных `IF`/`END IF` и без
`DO WHILE`. Использованы только:

- арифметический и логический `IF ... GOTO`;
- `DO` с переменной-счётчиком и меткой окончания;
- `REAL`/`INTEGER`-массивы и стандартные функции `ABS`, `EXP`, `IABS`.

Целая арифметика в этой реализации ограничена, поэтому большие числа
(например, упаковка матриц) требуют отдельных решений.
