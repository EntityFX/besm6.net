# Учебные примеры выполнения команд Мадлен

Пять заданий к главе [Как процессор БЭСМ-6 выполняет программы на Мадлен](../../book/09-execution-madlen.md).

| Задание | Основная тема | Сообщение при совпадении результатов |
|---|---|---|
| [01-arithmetic.dub](01-arithmetic.dub) | Арифметическое выражение, RESULT = 12 | `OK 01` |
| [02-branches.dub](02-branches.dub) | Максимум, знак разности и сравнение кодов | `OK 02` |
| [03-loop.dub](03-loop.dub) | Сумма четырёх элементов, нулевая длина и один проход | `OK 03` |
| [04-nested-loops.dub](04-nested-loops.dub) | Матрица 2 × 3, сумма 21 | `OK 04` |
| [05-functions.dub](05-functions.dub) | Вложенные вызовы и аргумент по адресу | `OK 05` |

Основная программа каждого задания называется `PROGRAM`, как ожидает обычный запуск `*EXECUTE` в «Дубне». Внутренние подпрограммы размещены в том же модуле. `*64` выводит сообщение, `*74` завершает задание. `FAIL01`…`FAIL05` означают несовпадение с ожидаемым результатом.

Окончательные версии подготовлены для отдельной проверки и **не проверены запуском**. Проверка должна подтвердить отсутствие ошибок трансляции, выполнение основной программы и ожидаемое сообщение после `*EXECUTE`. Появление слова `OK` внутри распечатанного исходника не считается успешным выполнением. Также нельзя считать достаточным один код завершения процесса.

Из корня репозитория в PowerShell:

```powershell
dotnet build src/Besm6.Cli/Besm6.Cli.csproj -c Release
dotnet src/Besm6.Cli/bin/Release/net8.0/besm6.dll run examples/learning-madlen/01-arithmetic.dub --limit 50000000 --no-wall-clock
```

Для остальных примеров замените имя файла. Лимит учитывает также выполнение монитора и исторического транслятора, поэтому он значительно больше количества команд в учебном алгоритме.

Для исследования предусмотрены параметры CLI `--trace` и `--trace-regs FILE`. Полная трасса включает работу системных программ; используйте адреса из листинга Мадлен, чтобы найти нужный участок.

Аппаратный обработчик прерывания сюда не включён: ему требуются профиль супервизора, настройка устройства и системный контекст, описанные в [главе о прерываниях](../../book/09-execution-madlen.md#9-ввод-и-вывод-экстракоды-и-прерывания-устройств).
