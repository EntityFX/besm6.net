## 2. Найденный баг: GOST-текст без терминатора

### 2.1 Диагностика

Слово `0551021720000000` (окт.) распаковывается на 6 байт:

| Байт | Значение | Ожидание |
|------|---------|----------|
| 0 (bits 47–40) | `0x16` | GOST-символ (H?) |
| 1 (bits 39–32) | `0x90` | GOST-символ (I?) |
| 2 (bits 31–24) | `0x8F` | **`0x7A` (G_END_OF_INFO) — НЕТ!** |
| 3 (bits 23–16) | `0x40` | — |
| 4 (bits 15–8) | `0x00` | — |
| 5 (bits 7–0) | `0x00` | — |

Ни один из 6 байт **не равен `0x7A`** (`G_END_OF_INFO`).

### 2.2 Механизм зацикливания

1. `E64` читает pointer → startAddr=515, endAddr=0 (без ограничения)
2. `E64` читает info → format=0 (GOST), finish=1
3. `E64PrintGost(515, 0)` начинает читать байты по адресу 515
4. Читает `0x16, 0x90, 0x8F, 0x40, 0x00, 0x00` — ни один ≠ `0x7A`
5. Переходит к адресу 516 → все нули → тоже ≠ `0x7A`
6. **∞** — бесконечное чтение из памяти → memory violation

### 2.3 Правильное слово

Для GOST-текста `H` + `I` + `END`:

```
byte0 = 0x27  (GOST H)
byte1 = 0x28  (GOST I)
byte2 = 0x7A  (G_END_OF_INFO)
byte3 = 0x00
byte4 = 0x00
byte5 = 0x00
```

```
word = (0x27 << 40) | (0x28 << 32) | (0x7A << 24)
     = 0x27287A000000
     = 0116241720000000 (окт.)
```

### 2.4 Исправление

Заменить 4-е raw-слово в `hello.dub`:

```diff
- `0551021720000000
+ `0116241720000000
```

## 5. Технические заметки

### 5.1 E64 protocol

```
E64(addr) →
  ptr = M[addr]          // pointer word
  startAddr = (ptr >> 29) & 0x7FFF
  endAddr   = (ptr >> 14) & 0x7FFF
  info  = M[addr+1]      // info word
  format = (info >> 44) & 0xF
  finish = (info >> 24) & 1

  if format == 0 → E64PrintGost(startAddr, endAddr)
  if format == 3 → E64PrintReal(startAddr, endAddr)
```

### 5.2 GOST-текст: требования к данным

- Каждое слово (48 бит) = 6 байт
- Байты читаются по порядку: byte0 (MSB), byte1, …, byte5
- Текст **обязан** заканчиваться байтом `0x7A` (G_END_OF_INFO)
- Если `endAddr = 0` → нет ограничения по адресу, только терминатор
- Нули (`0x00`) **не являются** терминатором

### 5.3 Float-формат BESM-6 (для math.dub)

```
bit 47     = sign
bits 46-39 = exponent (8 bits, excess-128)
bits 38-0  = mantissa (39 bits)
value = (-1)^sign × (1 + mantissa/2^39) × 2^(exp-128)
```

Пример: `2.0 = sign(0) × (1.0) × 2^1 → exp=129=0x81, mantissa=0`
```
word = (129 << 39) = 0x408000000000 = 2010000000000000 (окт.)
```
